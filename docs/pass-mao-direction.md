# PASS MAO — direction contract
Mode: Persuade. User delegates artistic direction, structure, copy and direct implementation. Code-led this session, with existing artwork; no standing workflow preference recorded.

## Concept
A studio reference library with the appetite of browsing record sleeves. The product is the courses, not a mock dashboard or membership-card illustration.

## Tokens
Paper #f6f7f9, ink #182b49, blue #2946d3, mist #e8ecf5, butter #f3e59b, white #ffffff. Bricolage Grotesque for display and course titles, system sans for body. Fluid 40–88px hero, 32–56px sections; 16px body minimum where primary reading matters. Rounded 12px covers, restrained controls, open sections.

## First viewport
Left-aligned headline “Toute ta musique. Un seul Pass.”, explicit subscription-library description, €39/month and €299/year, join CTA. Right side: six named course sleeves in a staggered library, not generic graphic decoration. Mobile: headline and price precede a compact three-cover shelf.

## Visitor path
Hero → large course explorer → permission to learn only what helps → Vince and optional community → transparent monthly/annual pricing → short FAQ → close.

## Signature interaction
Need chips jump to a relevant filtered library; category filters and text search narrow the real catalogue. Eight initial covers keep the page short, progressive disclosure exposes every course. Native expandable details reveal useful course descriptions, rather than sending the visitor away.

## Review against brief
Reject a carousel hiding most of the product, a SaaS tile grid as the whole page, and a long programme-led narrative. Reserve cards for the courses themselves. Keep no decorative waveform graphics, auto-playing motion or fabricated social proof. Preserve existing site navigation and theme behavior. Route-specific CSS must not restyle other pages.
